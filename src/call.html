How is this private?

Video, voice, chat and files go between the browsers in the call, encrypted. The call's secret key is the part of the link after the #, which your browser never sends to any server. Anyone with the full link can knock, so share it only with people you trust. We store nothing about your calls. Other services do touch a call: a free public introduction server (PeerJS) sees your IP address and a scrambled room name while browsers find each other, but not what is said; Cloudflare hosts this page and sees visits like any web host; and only if your network blocks a direct path, an encrypted relay (metered.ca) carries the call. People in a call can see each other's IP addresses. The encryption has not been independently audited, so do not rely on it for life-or-death secrecy. Open source: github.com/arbonomous/mut3d
